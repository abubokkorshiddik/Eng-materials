Intermediate level

Conditionals

If-sentences link a condition to a result. The tense shows how real or unlikely the condition is.

In plain words

A conditional sentence has two halves: the if-part (the condition) and the main part (the result). The surprise is that English changes tense to show how likely something is. Facts use present tenses. Real possibilities use present + will. Imaginary situations step back one tense: past + would. Impossible pasts step back again: past perfect + would have. Think of the tenses as distance from reality.

How to build it

Zero If + present, present: If you heat ice, it melts.

First If + present, will + base: If it rains, I will stay home.

Second If + past, would + base: If I had time, I would travel.

Third If + past perfect, would have + participle: If I had known, I would have called.

Mixed If + past perfect, would + base: If I had studied, I would be a doctor now.

When we use it

Zero: general truths

If you mix red and blue, you get purple.

Always true. You can replace if with when.

First: a real future possibility

If prices rise, people will buy less.

Likely or possible. Good for predictions, warnings and solutions.

Second: unlikely or imaginary now

If I were president, I would cut taxes.

Imaginary. Use were for every subject in formal English.

Third: impossible past

If she had left earlier, she would have caught the train.

It did not happen. Used for regret and explanation.

Mixed: past cause, present result

If I had saved more, I would be comfortable now.

A past condition with a present result.

Easy to mix up

If I see him, I will tell him.
If I saw him, I would tell him.

Real possibility vs unlikely or imaginary.

If I were you, I would apologise.
If I was you, I would apologise.

Were is the safer, formal choice.

Unless you hurry, you will be late.
If you don’t hurry, you will be late.

Unless means if not.

If I had known, I would have called.
Had I known, I would have called.

The second is a formal inverted form.

The two halves can swap places. When the if-part comes first, put a comma after it.

Mistakes people make

If it will rain, I will stay home. → If it rains, I will stay home.

No will in the if-part.

If I would have time, I would go. → If I had time, I would go.

No would in the if-part.

If I had known, I will call you. → If I had known, I would have called you.

Match the two halves.

If I was rich, I would help. → If I were rich, I would help.

Were is correct in formal English.

Unless you don’t study, you will fail. → Unless you study, you will fail.

Unless is already negative.

If he would study, he would pass. → If he studied, he would pass.

Would belongs in the result part.

Going deeper

Core test: how real is it?

Is it a general truth, a real possibility, an imaginary present or an impossible past? That tells you zero, first, second or third.

Modals in the result

Will, would, could, might, can, should: If you study, you might pass. If I had time, I could help.

Other ways to say if

Unless, as long as, provided that, on condition that, otherwise: You can go provided that you finish. Take a coat, otherwise you will be cold.

Wish and if only

I wish I had more time (now). I wish I had studied (past). If only I knew. The tense steps back, just like second and third conditionals.

Formal inversion

Should you need help, call us. Were I you, I would wait. Had I known, I would have called.

Conditionals in Task 2

First conditional for solutions: If governments invest in public transport, congestion will fall. Second for hypotheses: If cars were banned, cities would be quieter. Third for the past: If more had been done earlier, the damage would have been smaller.

Shortcuts that work in exams

  • No will or would after if. They belong in the result part.
  • Present → will. Past → would. Past perfect → would have. The three main pairs.
  • Were for all subjects. If I were, if he were.
  • Comma after an opening if-part. If it rains, we stay.

Where exams try to catch you

  • “When” and “if”: When means it will happen. If means it might.
  • “In case”: Take an umbrella in case it rains is a precaution, not the same as if.
  • Mixed forms: Look for words like now or today with a past perfect if-part.
  • “Unless … not”: A double negative. Wrong.

What to do, and what to leave alone

Do

  • Decide first how real the situation is.
  • Keep will and would out of the if-part.
  • Use were in second conditional.
  • Put a comma after an opening if-part.

Don’t

  • Don’t say if + will.
  • Don’t mix up the pairs.
  • Don’t use unless with a negative.
  • Don’t use would have in the if-part.

Why we get it wrong

Tense logic

Learners expect past tense to mean past time. In conditionals it means unreal.

Try this: Think “distance from reality”, not “time”.

Translation

In many languages the future form is allowed after if.

Try this: Memorise “if + present” as a chunk.

Too many forms

Five types feels like a lot.

Try this: Master first and second conditional first, then add the others.

Small habits that help

  • Write one real and one imaginary sentence about your week.
  • Use if once in each Speaking answer.
  • Redo wrongly answered sentences in your notebook.

In IELTS and real life

  • Speaking: talk about imaginary situations. “If I won the lottery, I would…”
  • Writing: first conditional for solutions, second for hypotheses, third for the past.
  • Reading: conditionals signal predictions and possibilities, not facts.
  • Listening: listen for if, unless, would and would have.

Real world: advising, warning, negotiating and apologising all use conditionals.

Two accurate conditionals are worth more than six confused ones.

Practice

Spot the mistake

  1. If it will rain, we stay home.
    Show answerIf it rains, we will stay home.: no will in the if-part.
  2. If I would have money, I would travel.
    Show answerIf I had money, I would travel.: no would in the if-part.
  3. If I knew, I would have called.
    Show answerIf I had known, I would have called.: third conditional needs past perfect.
  4. Unless you don’t hurry, you’ll be late.
    Show answerUnless you hurry, you’ll be late.: unless is already negative.

Say it another way

  1. Use second conditional: “I don’t have time. I can’t travel.”
    Show answerIf I had time, I could travel.
  2. Use third conditional: “I didn’t study. I failed.”
    Show answerIf I had studied, I would not have failed.

Fill the gaps

If you heat water, it (1) ___ (boil). If it rains, I (2) ___ (stay) at home. If I (3) ___ (be) rich, I would help. If she (4) ___ (study), she would have passed. (5) ___ you don’t leave now, you will be late (If / Unless).

Show answers1 boils · 2 will stay · 3 were · 4 had studied · 5 If

Speak and write

  • Talk for one minute: “If I could change one thing about my city, I would…”
  • Write one sentence of each type: zero, first, second, third.

Making it stick

  • Write one sentence of each conditional type about your own life, then check the tense pair.
  • Keep a small notebook of your own mistakes. Write the wrong sentence, the right one, and why. Read it every other day.
  • Redo the quiz after a day, three days and a week.
  • Read examples aloud, then write three about your own life.
